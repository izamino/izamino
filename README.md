# تفکرناب آینده اروند — مجتمع مسجد‌محور شباب اهل‌الجنه

بازطراحی کامل صفحهٔ معرفی مؤسسهٔ فرهنگی هنری تفکر ناب آینده اروند و مجتمع
مسجد‌محور شباب اهل‌الجنه آبادان.

نسخهٔ قبلی یک باندل تک‌فایلی React/Vite بود (همهٔ تصاویر به‌صورت Base64 داخل
HTML). این نسخه یک سایت ایستای ساده است: HTML معنایی + CSS + جاوااسکریپت بدون
وابستگی، بدون مرحلهٔ build.

---

## چه چیزی عوض شد

**چیدمان دقیقاً همان قبل است** — همان بخش‌ها، به همان ترتیب، با همان متن‌ها،
شماره‌ها، لینک‌ها و تصاویر. چیزی حذف نشده. آنچه عوض شده، پوستهٔ بصری و
جزئیات حرکتی است:

### زبان بصری: مدرن + سنتی

- **تایپوگرافی:** فونت **اَبَر (Abar 2.2 Pro)** به‌صورت Variable Font. محور
  `CNTR` این فونت (کنتراست) پایهٔ تلفیق است: متن‌های بدنه روی `CNTR 0`
  (کم‌کنتراست، هندسی، مدرن) و همهٔ تیترها روی `CNTR 100` (پرکنتراست،
  خوشنویسانه، سنتی). یک فایل ۱۵۰ کیلوبایتی جای ۳۰ فایل استاتیک را می‌گیرد.
- **نقش‌مایهٔ هندسی:** ستارهٔ هشت‌پر (رُبع‌الحزب) به‌صورت SVG درون‌خط، با
  اوپَسیتی بسیار پایین روی سربرگ، منو، کارت‌ها، بخش رسانه و پاورقی.
- **جزئیات قاب:** گوشه‌های تزئینی طلایی روی کارت‌ها، خط‌های زینتی لوزی‌دار زیر
  تیتر بخش‌ها، ماسک طاق روی نقش‌مایهٔ بخش مشارکت.
- **پالت:** سبز عمیق مسجدی، طلایی، و زمینهٔ کاغذی گرم — بازتعریف‌شده روی
  توکن‌های CSS.

### حرکت و تعامل

- ظاهر شدن تدریجی بخش‌ها هنگام اسکرول (`IntersectionObserver`) با تأخیر پلکانی.
- جمع شدن و شیشه‌ای شدن سربرگ هنگام اسکرول + نشانه‌گذاری بخش فعال در منو.
- پارالاکس ملایم روی تصویر هیرو.
- کشوی موبایل با قفل اسکرول، بستن با `Esc`، بک‌دراپ و تلهٔ فوکوس.
- آکاردئون‌ها با `grid-template-rows: 0fr → 1fr` (بدون محاسبهٔ ارتفاع با JS).
- حلقهٔ پیشرفت با انیمیشن `stroke-dashoffset` و شمارندهٔ عددی فارسی؛ نوارهای
  پیشرفت هنگام ورود به کادر دید پر می‌شوند.
- پانوراما: هر نما با بزرگ‌نمایی/جابه‌جایی متفاوت و محو تدریجی.
- دکمهٔ کپی شماره کارت/شبا با `navigator.clipboard` و فالبک `execCommand`.
- **همهٔ این‌ها زیر `prefers-reduced-motion: reduce` خاموش می‌شوند.**

### دسترس‌پذیری و کیفیت

- `dir="rtl"`، `lang="fa"` و استفاده از ویژگی‌های منطقی CSS
  (`inset-inline`, `border-inline`, `padding-inline`).
- لینک «پرش به محتوای اصلی»، `aria-expanded` / `aria-controls` روی همهٔ
  آکاردئون‌ها و تب‌ها، `role="tablist"`، و حلقهٔ فوکوس قابل‌دیدن.
- بهبود تدریجی: بدون جاوااسکریپت هم تمام متن‌ها دیده می‌شوند.
- بدون سرریز افقی در ۳۲۰ تا ۱۹۲۰ پیکسل.

## اجرا

بدون وابستگی و بدون build. کافی است پوشه را روی هر وب‌سروری قرار دهید:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## مجوز فونت

فونت **اَبَر** نرم‌افزاری **مالکیتی/تجاری** از [fontiran.com](https://fontiran.com)
است (نسخهٔ ۲.۲، طراح: رضا بختیاری‌فرد). فایل‌های `assets/fonts/` طبق پروانهٔ
خریداری‌شدهٔ صاحب اثر در این پروژه به کار رفته‌اند. پیش از استفاده در پروژه‌ای
دیگر، پروانهٔ جداگانه از فونت‌ایران تهیه کنید.

تصاویر و متن‌ها متعلق به مجموعهٔ تفکر ناب آینده اروند و مسجد شباب اهل‌الجنه است.
