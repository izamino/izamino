# کارتابل اداری مجتمع مسجدمحور شباب اهل‌الجنه — نسخه ۳ (PHP)

بسته نصب روی هاست معمولی PHP/MySQL: `dist/kartabl-shabab-v3.zip` — راهنمای نصب داخل بسته: `php/README.txt`.

## ساختار

```
config/org.mjs      پیکربندی مشترک: ۱۸ مدیریت، خدمات، فضاها، مجوزها (وابستگی، قابل واگذاری، حساس)، ابزارهای اختصاصی هر مدیریت، کدینگ حساب‌ها
src/*.js, styles.css رابط کاربری (تک‌صفحه‌ای، راست‌چین، گوشی/آیپد/رایانه)
php/                برنامه روی هاست
  index.php         صفحه سامانه       api.php   درگاه برنامه      install.php  نصب یک‌مرحله‌ای
  cli.php           ابزار خط فرمان (بازنشانی رمز، پشتیبان، زمان‌بندی، بررسی رویدادها، نسخه آزمایشی)
  lib/              منطق سرور: db، core (مجوزها)، rules، ops_work، ops_fin، ops_tools، ops_admin، view، auth، maint
  assets/           app.js، app.css، قلم وزیرمتن (محلی؛ بدون وابستگی به گوگل)
  data/             پایگاه SQLite (اختیاری)، پیوست‌ها، پشتیبان‌ها — با .htaccess بسته
test/api-test.mjs   ۱۰۱ آزمون سرور            test/ui-e2e.cjs  ۱۸ آزمون مرورگر
```

## ساخت و آزمون

```
node build.mjs --zip                         # assets + org.json + dist/kartabl-shabab-v3.zip
cd php && php cli.php demo /tmp/kt           # نسخه آزمایشی SQLite (رمز همه ۱۲۳۴)
php -S 127.0.0.1:8090                        # اجرای محلی
node ../test/api-test.mjs http://127.0.0.1:8090/
node ../test/ui-e2e.cjs http://127.0.0.1:8090/
```

هر دو مجموعه آزمون روی SQLite و MariaDB ۱۰٫۱۱ اجرا و پاس شده‌اند؛ بسته روی Apache + mod_php نصب و دسترسی‌ناپذیری `data/`، `lib/`، `config.php` و `cli.php` بررسی شده است.

## اصول

- هر عملیات روی سرور با مجوز جایگاه بررسی می‌شود؛ هر کاربر فقط داده مجاز پنل خود را دریافت می‌کند.
- اختیار مسئول دفتر و منشی را مدیر همان بخش تعیین می‌کند (دادن یا گرفتن، فقط در سقف اختیار خود مدیر که امام جماعت تعیین می‌کند)؛ مجوزهای وابسته بدون مجوز پایه کار نمی‌کنند.
- نام کاربری و رمز فقط با مدیر فناوری اطلاعات؛ متصدی فقط نام و مشخصات خود را ثبت می‌کند.
- همه تغییرات در قفل و تراکنش؛ شناسه یکتای هر عملیات از ثبت تکراری جلوگیری می‌کند؛ نسخه هر رکورد از بازنویسی هم‌زمان.
- رویدادها با زنجیره SHA-256 در جدول جدا؛ پشتیبان روزانه فشرده با آزمون بازیابی.
