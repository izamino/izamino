# کارتابل اداری مجتمع مسجدمحور شباب اهل‌الجنه

سامانه تحت وب، فارسی، راست‌چین و واکنش‌گرا برای مدیریت امور اداری مدیریت‌های مستقل زیر نظر امام جماعت.

دو نسخه از یک کد ساخته می‌شود:

| نسخه | کاربرد | داده |
|---|---|---|
| **نسخه سروری (عملیاتی)** — `server/` | بهره‌برداری واقعی چندکاربره | پایگاه داده SQLite روی سرور؛ مرورگر هیچ داده‌ای نگه نمی‌دارد |
| نسخه نمایشی — `dist/index.html` و پیش‌نمایش claude.ai | آشنایی و آزمایش | داده نمونه در مرورگر؛ برای اطلاعات واقعی مناسب نیست |

## راه‌اندازی نسخه سروری

نیازمندی: **Node.js 22.5 یا بالاتر** (بدون هیچ بسته اضافه؛ SQLite و scrypt داخلی Node استفاده می‌شوند).

```bash
cd kartabl
node build.mjs                                   # ساخت فایل‌های رابط کاربری
cd server
npm run init                                     # پایگاه داده خالی: ۵۲ جایگاه، بدون کاربر و بدون داده نمونه
node --disable-warning=ExperimentalWarning server.js create-user --pos P0 --username imam --name "نام امام جماعت"
node --disable-warning=ExperimentalWarning server.js create-user --pos P16-m --username it.admin --name "نام مدیر فناوری اطلاعات" --phone 0912xxxxxxx
npm start                                        # http://127.0.0.1:8080
```

هر `create-user` یک رمز موقت تصادفی چاپ می‌کند که در اولین ورود باید عوض شود. بقیه کاربران را مدیر فناوری اطلاعات از «پنل مدیریت سامانه» تعریف می‌کند یا افراد از صفحه ورود «درخواست ایجاد حساب» می‌دهند.

### استقرار روی سرور

- فایل‌های نمونه در `server/deploy/`: سرویس systemd و پیکربندی nginx با HTTPS.
- پشت HTTPS حتماً `COOKIE_SECURE=1` و پشت nginx `TRUST_PROXY=1` تنظیم شود.
- متغیرها: `PORT`، `HOST`، `DATA_DIR` (محل پایگاه داده، فایل‌ها و نسخه‌های پشتیبان).

### فرمان‌های سرور

| فرمان | کار |
|---|---|
| `server.js init` | ساخت پایگاه داده خالی عملیاتی |
| `server.js init --demo` | پایگاه آزمایشی با داده نمونه (رمز همه ۱۲۳۴) — **فقط برای آزمایش** |
| `server.js create-user --pos <جایگاه> --username <نام> --name <نام کامل>` | تعریف متصدی جایگاه با رمز موقت |
| `server.js reset-password --username <نام>` | رمز موقت جدید (مثلاً اگر امام جماعت رمز را فراموش کند) |
| `server.js backup` | نسخه پشتیبان فوری |
| `server.js verify-audit` | بررسی سلامت زنجیره رویدادها |

### پیامک

در «پنل مدیریت › پیامک» سرویس‌دهنده (کاوه‌نگار یا درگاه اختصاصی)، کلید و شماره خط را وارد کنید و «ارسال پیامک آزمایشی» را بزنید. وضعیت هر پیامک واقعی است: در صف ارسال، ارسال‌شده، تحویل‌شده، تحویل نشد، ناموفق. کلید فقط روی سرور می‌ماند و متن پیامک هیچ جزئیات محرمانه‌ای ندارد.

### آزمون‌ها

```bash
node test/server-test.mjs   # ۸۴ آزمون امنیت و درستی سرور
node test/ui-test.mjs       # پیمایش کامل رابط روی سرور، تزریق HTML، فوکوس، گوشی و آیپد (نیازمند Playwright)
```

## ساختار کد

| فایل | محتوا |
|---|---|
| `src/core.js` | تاریخ شمسی، ساختار سازمانی، سالن‌ها و انواع برنامه، مجوزها، رویدادها |
| `src/domain.js` | قواعد و گردش کار و اعتبارسنجی‌های مشترک |
| `src/domain-admin.js` | کاربران، رمز، دسترسی‌ها، عضویت، تأیید مدیریتی، تنظیمات |
| `src/ops.js` | **تنها مسیر تغییر داده**: فهرست عملیات مجاز با بررسی مجوز |
| `src/ui.js`، `src/pages*.js`، `src/admin.js` | رابط کاربری |
| `src/remote.js` | اتصال رابط به سرور |
| `src/sync.js` | همگام‌سازی پیش‌نمایش claude.ai (فقط نسخه نمایشی) |
| `server/server.js` | سرور: ورود، نشست، تراکنش، فایل، پیامک، پشتیبان |
| `server/view.js` | تعیین داده مجاز هر کاربر |
| `server/vendor/qrcode-generator.js` | تولید QR (کتابخانه MIT، Kazuhiko Arase) |
