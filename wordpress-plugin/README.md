# افزونه وردپرس «سامانه انبار شباب»

سامانه مدیریت انبارهای **مجتمع مسجد محور شباب — مجموعه تفکر ناب** به‌صورت افزونه وردپرس.

- `anbar-shabab/` — کد افزونه
- `anbar-shabab.zip` — فایل آماده نصب (افزونه‌ها › افزودن › بارگذاری افزونه)
- `tests/api.test.js` — آزمون سرتاسری روی یک وردپرس در حال اجرا

## نصب

1. فایل `anbar-shabab.zip` را در پیشخوان وردپرس بارگذاری و فعال کنید.
2. در «تنظیمات › انبار شباب» جدول حساب‌ها و رمزهای اولیه را بچسبانید و حساب‌ها را بسازید.
3. به نشانی `yoursite.com/anbar` بروید؛ مسئولان وارد می‌شوند و افراد بدون حساب «درخواست وسیله» ثبت می‌کنند.

جزئیات بیشتر در `anbar-shabab/readme.txt`.

## ساختار افزونه

```
anbar-shabab.php      معرفی افزونه، فعال‌سازی، زمان‌بندی‌ها
includes/db.php       جدول‌ها (wp_anbar_*) و پشتیبان‌گیری
includes/users.php    مجوزها و محدوده هر نفر، حساب‌های اولیه
includes/stock.php    موجودی، رزرو، درخواست خروج ← تأیید ← تحویل، امانت، انتقال، اصلاح
includes/tickets.php  درخواست عمومی وسیله و تیکت‌ها
includes/catalog.php  شناسنامه اموال: انواع وسیله، فیلدهای اختصاصی، موارد ناقص
includes/notify.php   اعلان‌ها، یادآوری امانت و انقضا، پیامک و پیام‌رسان
includes/rest.php     REST API زیر /wp-json/anbar/v1
includes/xlsx.php     خروجی اکسل
includes/frontend.php برگه تمام‌صفحه سامانه
includes/admin.php    تنظیمات › انبار شباب (ساخت حساب‌های اولیه، پیامک)
assets/               رابط کاربری (JS/CSS، فونت وزیرمتن)
```

## آزمون

فقط روی یک سایت آزمایشی (اطلاعات انبار پاک و ۱۵ حساب با رمز آزمایشی `test-<username>` ساخته می‌شود):

```bash
wp eval-file wordpress-plugin/tests/reset.php
WP_URL=http://localhost:8080 node --test wordpress-plugin/tests/api.test.js
```

هر آزمون یکی از معیارهای تحویل را بررسی می‌کند (دسترسی‌ها، سه‌مرحله‌ای بودن خروج، رزرو، امانت و انتقال، تیکت عمومی، مدیریت کاربران، گزارش‌ها).

## مجوزها

افراد کاربران وردپرس با نقش «کاربر سامانه انبار» هستند. مجوزهای هر نفر مستقل از هم در `anbar_perms` ذخیره می‌شود:
محدوده انبار (همه یا انتخابی)، ثبت و ویرایش شناسنامه، ثبت ورود، درخواست خروج، تأیید خروج، ثبت تحویل، مدیریت کاربران،
بررسی تیکت، پیگیری تیکت و مسئول شناسنامه. همه این قواعد در سرور بررسی می‌شوند. فهرست حساب‌های اولیه در
`includes/users.php` است؛ رمزها در کد نیستند و از صفحه تنظیمات وارد می‌شوند.
