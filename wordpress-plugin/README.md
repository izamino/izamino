# افزونه وردپرس «سامانه انبار شباب»

سامانه مدیریت انبارهای **مجتمع مسجد محور شباب — مجموعه تفکر ناب** به‌صورت افزونه وردپرس.

- `anbar-shabab/` — کد افزونه
- `anbar-shabab.zip` — فایل آماده نصب (افزونه‌ها › افزودن › بارگذاری افزونه)
- `tests/api.test.js` — آزمون سرتاسری روی یک وردپرس در حال اجرا

## نصب

1. فایل `anbar-shabab.zip` را در پیشخوان وردپرس بارگذاری و فعال کنید.
2. به نشانی `yoursite.com/anbar` بروید و با حساب مدیر سایت وارد شوید.
3. از بخش «کاربران» برای هر نفر حساب بسازید و انبارهایی را که مدیرشان است تیک بزنید.

جزئیات بیشتر در `anbar-shabab/readme.txt`.

## ساختار افزونه

```
anbar-shabab.php      معرفی افزونه، فعال‌سازی، زمان‌بندی‌ها
includes/db.php       جدول‌ها (wp_anbar_*) و پشتیبان‌گیری
includes/users.php    نقش‌ها و دسترسی (anbar_access / anbar_manage)، مدیران هر انبار
includes/stock.php    همه عملیات موجودی: ورود، خروج، امانت، انتقال، اصلاح
includes/notify.php   اعلان‌ها، یادآوری امانت و انقضا، پیامک و پیام‌رسان
includes/rest.php     REST API زیر /wp-json/anbar/v1
includes/xlsx.php     خروجی اکسل
includes/frontend.php برگه تمام‌صفحه سامانه
includes/admin.php    تنظیمات › انبار شباب
assets/               رابط کاربری (JS/CSS، فونت وزیرمتن)
```

## آزمون

```bash
WP_URL=http://localhost:8080 WP_ADMIN_PASS=... node --test wordpress-plugin/tests/api.test.js
```
روی یک نصب تازه اجرا شود؛ کاربرهای آزمایشی ali، reza و hasan ساخته می‌شوند.

## ساختار داده‌ها

افراد همان کاربران وردپرس هستند. نقش «کاربر انبار» فقط مشاهده و درخواست دارد؛ مدیر هر انبار در جدول
`wp_anbar_warehouse_managers` مشخص می‌شود؛ نقش «مدیر کل انبار» و مدیران سایت به همه انبارها و مدیریت کاربران دسترسی دارند.
