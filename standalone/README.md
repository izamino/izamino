# سامانه انبار شباب — نسخه مستقل (بدون وردپرس)

مدیریت اموال، انبارها، درخواست وسیله و تأیید خروج کالا — مجتمع مسجد محور شباب، مجموعه تفکر ناب.

## پیش‌نیاز

هر هاست معمولی PHP (سی‌پنل، دایرکت‌ادمین یا مشابه):

- PHP نسخه ۷٫۴ یا بالاتر با افزونه‌های `mysqli`، `json`، `mbstring` (و `curl` فقط برای پیامک)
- یک پایگاه داده خالی MySQL یا MariaDB
- گواهی SSL (HTTPS) برای امنیت رمزها

## نصب

1. در کنترل‌پنل هاست یک پایگاه داده MySQL و یک کاربر برای آن بسازید.
2. فایل `anbar-shabab-standalone.zip` را در هاست (مثلاً در `public_html`) بارگذاری و از حالت فشرده خارج کنید.
   پوشه `anbar-shabab` ساخته می‌شود؛ می‌توانید نامش را مثلاً به `anbar` تغییر دهید.
3. در مرورگر به `https://yoursite.com/anbar/install.php` بروید و:
   - اطلاعات پایگاه داده را وارد کنید؛
   - جدول حساب‌ها و رمزهای اولیه را از سند راه‌اندازی بچسبانید (هر خط: نام کاربری، فاصله، رمز)؛
   - «نصب» را بزنید.
4. نشانی سامانه: `https://yoursite.com/anbar/` — صفحه ابتدایی دو مسیر دارد: «ورود مسئولان» و «درخواست وسیله».

نصب‌کننده فقط یک بار کار می‌کند. پس از ساخت حساب‌ها، دوباره قابل اجرا نیست.

## پس از نصب

- **تنظیمات** (نام مجموعه، پیامک، حساب‌های ساخته‌نشده): از منوی «بیشتر › تنظیمات سامانه» برای کسانی که مجوز «مدیریت کاربران» دارند.
- **کارهای زمان‌بندی‌شده** (یادآوری امانت و انقضا، پشتیبان روزانه) با بازدید عادی سامانه اجرا می‌شوند و کران لازم نیست.
- **پشتیبان**: هر روز یک نسخه از اطلاعات در `data/anbar-private/backups` ذخیره می‌شود و از «بیشتر › پشتیبان‌گیری» قابل دانلود است.
  از پایگاه داده هم در کنترل‌پنل هاست پشتیبان منظم بگیرید.
- **به‌روزرسانی**: فایل‌های نسخه جدید را روی قبلی بریزید و `config.php` و پوشه `data` را نگه دارید؛ جدول‌ها خودکار به‌روز می‌شوند.

## امنیت

- پوشه‌های `data`، `includes` و `lib` با `.htaccess` بسته شده‌اند (آپاچی و لایت‌اسپید).
  اگر وب‌سرور شما Nginx است، دسترسی مستقیم به این سه پوشه را در تنظیمات Nginx ببندید.
- رمزها با `password_hash` ذخیره می‌شوند؛ هر درخواست تغییر داده یک توکن نشست دارد.
- رمزهای اولیه در کد برنامه نیستند و فقط در صفحه نصب وارد می‌شوند.

## ساختار

```
index.php          صفحه سامانه و API (index.php?api=/...)
install.php        نصب یک‌مرحله‌ای
settings.php       تنظیمات برای مدیران کاربران
includes/          منطق سامانه (مشترک با نسخه وردپرس)
lib/compat.php     جایگزین توابع وردپرس: کاربران، نشست، پایگاه داده
assets/            رابط کاربری و فونت وزیرمتن
data/              تصاویر و پشتیبان‌ها (ساخته می‌شود)
```
